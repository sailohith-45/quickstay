# QuickStay Client

Frontend application for QuickStay, built with **React 19**, **Vite**, and **Tailwind CSS v4**.

## Scripts

- `npm run dev`: Start Vite development server
- `npm run build`: Compile production bundle
- `npm run lint`: Run ESLint checks
- `npm run preview`: Preview production build locally

## Setup

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
2. Configure `VITE_CLERK_PUBLISHABLE_KEY` and `VITE_BACKEND_URL`.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start dev server:
   ```bash
   npm run dev
   ```
